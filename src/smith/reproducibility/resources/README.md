# SMITH Reproducibility Layer

This directory maps each main Results section to one representative executable example. It does not claim that every panel of every manuscript figure is rebuilt by the default examples.

Use `smith-repro list`, `smith-repro check --data-root data/tutorials`, and `smith-repro run <case> --data-root data/tutorials` after installing the package. The public package no longer treats aggregate result tables as tutorial inputs.
