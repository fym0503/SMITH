# SMITH-Agent

This example covers two auditable Agent stages: multi-reference panel evaluation and integrated probe feasibility.

```bash
smith-repro run 05_agent
```

The summary contains mean MERFISH classification accuracy by panel source and feasibility pass rates from a compact example. Full Figure 6 additionally requires public reference retrieval, repeated SMITH runs, a locked MERFISH test, ODT, BLAST indexes, ProbeDealer resources and Pareto-guided hyperparameter search.
