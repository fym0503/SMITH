# Package component manifest

| Component | Role |
|---|---|
| `src/smith/` | Core stochastic-gate panel-selection model and evaluation helpers |
| `src/smith_agent/` | Agent CLI, registries, evaluation and feasibility adapters |
| `configs/agent/` | Default datasets, task profiles, tools and backend settings |
| `scripts/` | Training, notebook, data and backend utilities |
| `reproducibility/` | Input checksums, reference values and runnable workflows |
| `docs/source/` | User documentation and executed biological tutorials |

H5AD inputs, run outputs, sessions and environment directories are stored separately from the source distribution.
