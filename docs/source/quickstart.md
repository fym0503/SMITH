# Quickstart

Install SMITH in editable mode:

```bash
python -m pip install -e .
```

## Select a panel from AnnData

Prepare an `.h5ad` file with target genes in `adata.var_names`. For cell-type selection, add labels in `adata.obs['celltype']`, `cell_type` or `subclass`.

```bash
python scripts/main.py \
  --adata_file data/your_reference.h5ad \
  --saving_dir outputs/my_panel \
  --log_dir outputs/my_panel/logs \
  --tasks recon,cls \
  --task_name celltype \
  --panel_size 64 \
  --epoch 100 \
  --device cpu
```

When spatial coordinates are stored in `adata.obsm['spatial']`, add the `coordination` task:

```bash
--tasks recon,cls,coordination
```

Use `--layer counts` to train from a named AnnData layer. Ranked targets and training logs are written to the output directories.

## Try the Agent CLI

```bash
smith-cli tools
smith-cli datasets
smith-cli models
smith-agent
```

The core optimizer can be tested with a small synthetic AnnData input generated by `scripts/make_smoke_h5ad.py`. This example is for a quick installation check; the biological tutorials use real study data.
